# PenPilot downloads

PenPilot is a standalone app for the **AxiDraw V3** pen plotter, on Mac and Windows. Put
drawings, photos and text (handwriting and Arabic fonts too) on a page, turn them into pen
lines, and plot them. Nothing else to install.

## Install

Get the files from the **[latest release](https://github.com/Ava-AgentOne/penpilot-releases/releases/latest)**:

**Mac** (Apple Silicon: M1 or newer): `PenPilot-…-mac-arm64.dmg`
1. Open it and drag **PenPilot** into **Applications**.
2. The first time you open it, macOS says it can't check the app (it isn't signed with a paid
   Apple certificate). Open **System Settings → Privacy & Security**, scroll down and press
   **Open Anyway**. (On older macOS: right-click PenPilot → **Open**.) You only do this once.

**Windows 10 / 11**: `PenPilot-Setup-….exe`
1. Run it. If Windows says "Windows protected your PC", press **More info → Run anyway**
   (only once).
2. Or use `PenPilot-Portable-….exe` to run PenPilot without installing it.

## Updates

PenPilot checks for new versions by itself. When one is ready it says so and offers
**Update now**; it then closes and opens again on the new version. On a Mac, keep PenPilot in
your **Applications** folder so it can update itself. **Help → Check for updates…** checks
straight away.
